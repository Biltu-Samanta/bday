# bday

A 3D virtual art museum built with [Babylon.js](https://www.babylonjs.com/) and [Vite](https://vitejs.dev/).

## Features
- **3 Classical & Modern Galleries**: The Grand Vestibule, Central Rotunda, and Lumina Pavilion.
- **Interactive Artwork Placards & Inspection**: Walk up to paintings and press `E` or click to inspect high-resolution photographs with smooth cinematic zoom.
- **Third-Person 3D Avatar**: Third-person camera with mouse-drag orbit and WASD controls.
- **Dynamic Spatial Audio**: Room-specific ambient music tracks with real-time crossfading and footstep sounds.
- **Interactive Double Doors**: Automatic sliding/swing doors between museum wings with realistic sound effects.
- **Photo Mode**: Capture in-game camera snapshots with instant polaroid previews.
- **In-Game Edit Mode**: Customize frames, positions, titles, and artwork images in real-time.

## Tech Stack
- **Engine**: Babylon.js 9+
- **Bundler**: Vite 8+
- **Deployment**: Vercel ready (`vercel.json`)

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
